Create Admin Password Vault

GitHub Pages is static, so this vault encrypts your repo publish token with AES-256-GCM behind your chosen Admin Password. Nobody can read or use it without your password.

  1. Open GitHub Fine-Grained Tokens.
  2. Select Only select repositories → pick your portfolio repo.
  3. Under Repository permissions, set Contents to Read and write, then generate token.
